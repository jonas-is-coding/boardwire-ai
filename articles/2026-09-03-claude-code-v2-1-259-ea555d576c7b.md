# Claude Code v2.1.259

New CLI features enable centralized enterprise deployment of Claude Code and headless automation, directly impacting builder workflows.

<h2>What's changed</h2>
<ul>
<li>Added <code>managedMcpServers</code> managed setting: organizations can provide HTTP/SSE MCP servers to every user (same entry shape as <code>.mcp.json</code>); entries that name a command to run are skipped</li>
<li>Added <code>--permission-prompts none</code> for unattended headless hosts: anything that would prompt is denied automatically while the active permission mode (including auto mode) keeps deciding</li>
<li>Added recognition of <code>glab mr create/merge/close/reopen/note/update</code> so GitLab merge requests show as <code>MR !N</code> in the collapsed tool summary and refresh the footer MR badge</li>
<li>Added <code>--json</code> to <code>claude plugin validate</code> for a machine-readable validation report</li>
<li>Fixed concurrent sessions silently reverting each other's <code>~/.claude.json</code> changes — workspace trust no longer resets and MCP/project state is no longer lost when running many sessions at once</li>
<li>Fixed a conversation whose thinking was rejected once being rejected again on every later turn</li>
<li>Fixed Bash <code>Read()</code> deny rules not covering files given as option values (<code>--ignore-revs-file=.env</code>, <code>-f.env</code>, <code>@file</code>), <code>git diff</code>/<code>git grep</code> file operands, or <code>cd DIR &amp;&amp; cat FILE</code> compounds; <code>grep -r</code>/<code>cp -r</code> over a directory holding a denied file now asks</li>
<li>Fixed the prompt cache being invalidated when the OAuth token refreshed in sessions with telemetry disabled</li>
<li>Fixed fullscreen mode showing a blank conversation after a long turn with hundreds of tool calls</li>
<li>Fixed auto mode running a turn on a model it doesn't support when a command or skill's frontmatter <code>model:</code> named one; the turn now keeps the session model</li>
<li>Fixed <code>CLAUDE_CODE_MAX_CONTEXT_TOKENS</code> being ignored for Vertex-style model IDs (<code>@YYYYMMDD</code> suffix) of model versions Claude Code doesn't recognize</li>
<li>Fixed the live output preview of a running shell command hiding its newest lines when an earlier line wrapped</li>
<li>Fixed a background GitHub connection check that ran on every launch for claude.ai users; the result is now remembered across launches</li>
<li>Fixed <code>--resume</code> failing (and <code>--continue</code> opening an empty conversation) when a saved session contains an attachment entry with no payload</li>
<li>Fixed frontmatter <code>model:</code> on custom commands and skills being ignored in interactive sessions</li>
<li>Fixed Artifact publishing failing once with an "unexpected parameter <code>note</code>" error in conversations continued from an older version</li>
<li>Fixed managed <code>forceRemoteSettingsRefresh</code> being ignored at startup when a policy helper configured by MDM or the managed settings file had already run</li>
<li>Fixed worktree isolation refusing hook-created worktrees on machines where <code>git rev-parse</code> fails with a message other than "not a git repository"</li>
<li>Fixed OpenTelemetry metrics and events from cloud sessions missing the <code>user.email</code>, <code>organization.id</code>, and <code>user.account_uuid</code> attributes</li>
<li>Fixed MCP servers that disconnect while their tools are being listed at startup showing as connected with no tools instead of reporting the error</li>
<li>Fixed the file edit permission dialog sometimes showing a changed line cut short with no indication</li>
<li>Fixed repository detection dropping a known repo identity after a transient git probe failure</li>
<li>Fixed managed settings silently going unenforced when the managed-settings file, a drop-in, the MDM plist, or the HKLM value cannot be parsed: Claude Code now refuses to start and names the source</li>
<li>Fixed Stop not actually stopping background agents and workflows in remote-control sessions: killed tasks now stay visible and re-stoppable until their processes exit</li>
<li>Fixed resuming a workflow run while its previous stopped run was still exiting, which could run duplicate copies of its agents</li>
<li>Fixed marketplace repo URLs on github.com with a trailing slash or dangling <code>?</code>/<code>#</code> producing an unusable <code>.git</code> clone URL</li>
<li>Fixed blocking Stop hooks causing the turn after a block to lose the model's reasoning from that turn and, on some models, miss the prompt cache</li>
<li>Fixed remote (claude.ai) sessions taking 60 seconds to start a turn after a browser-hosted MCP server's page had gone away</li>
<li>Fixed worktree-isolated sessions refusing common Bash loops, xargs pipelines and launcher-wrapped commands that cannot reach the main checkout</li>
<li>Improved terminal resize and first-render performance for long responses by reusing text measurements</li>
<li>Improved <code>/workflows</code> agent detail: JSON outcomes are pretty-printed with syntax colors and real line breaks, and long outcomes fold behind an expand toggle</li>
<li>Improved headless/SDK session start: the first turn begins up to 50 ms sooner when MCP servers finish connecting</li>
<li>Improved <code>/install-github-app</code> to explain it is GitHub-only and point to the GitLab CI/CD docs when run inside a GitLab repository</li>
<li>Improved nested background subagent results to be saved in the parent subagent's transcript, so resumed subagents keep them and shared transcripts show the delivery</li>
<li>Changed <code>allowedMcpServers</code> to govern only servers users add: a literal <code>managed-mcp.json</code> server your allowlist used to filter out now loads on upgrade; use <code>deniedMcpServers</code> to keep it off</li>
<li>[VSCode] Added an Active quick filter and a status filter menu (Needs input, Working, Completed) to the session list sidebar</li>
<li>Fixed remote and scheduled sessions doing nothing after a connector-tool permission prompt was approved while the session was paused</li>
</ul>

This story surfaced via Claude Code Releases. For the original details and any numbers we have not confirmed here, follow the source below.
