# Ollama v0.32.8

<h2>Muse Glimmer</h2>
<p>Muse Glimmer is now available on all platforms. Muse Glimmer can power coding agent applications such as Claude Code, Codex, Pi and more, as well as long-running personal assistants such as OpenClaw and Hermes.</p>
<p>Ollama's MLX engine provides state-of-the-art performance on Apple Silicon for this model, with support for DFlash and image input as of Ollama 0.32.7.</p>
<p>To download and run Muse Glimmer locally:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto"><pre>ollama run muse-glimmer</pre></div>
<p>To run Muse Glimmer with Claude Code, <a href="https://ollama.com/download" rel="nofollow">download Ollama</a> and run:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto"><pre>ollama launch claude --model muse-glimmer</pre></div>
<p>For a lighter-weight coding agent, try <a href="https://pi.dev" rel="nofollow">Pi</a>:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto"><pre>ollama launch pi --model muse-glimmer</pre></div>
<p>For personal assistant frameworks such as OpenClaw and Hermes, use:</p>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto"><pre>ollama launch openclaw --model muse-glimmer</pre></div>
<div class="highlight highlight-source-shell notranslate position-relative overflow-auto"><pre>ollama launch hermes --model muse-glimmer</pre></div>
